# Data sources — what was attempted, what was actually used

## Attempted first (public, no-key paths, via curl, 2026-11-04)

### 1. Census API — FAILED (key required in this environment)

- URL attempted:
  `https://api.census.gov/data/2023/acs/acs5?get=NAME,B19013_001E&for=metropolitan%20statistical%20area:*`
- Result: **HTTP 302** to `https://api.census.gov/data/missing_key.html`,
  with response header `X-DataWebAPI-KeyError: 1`.
- The same 302 was reproduced by `src/fetch_data.py` (curl probe, no
  redirect following) and recorded in `outputs/metrics.json`
  (`fetch_attempts`).
- Intended use if it had worked: ACS 5-year median household income
  (`B19013_001E`) by metropolitan statistical area. No Census values were
  retrieved, so **no Census value appears in this project**.

### 2. FRED graph CSV — SUCCEEDED but NOT USABLE for this model

- URL attempted: `https://fred.stlouisfed.org/graph/fredgraph.csv?id=UNRATE`
- Result: **HTTP 200**, a valid CSV (946 lines at time of check, latest
  rows through 2026-09).
- Why not used: UNRATE is a **single national unemployment series**, not
  metro-level demand, labor-cost, or competition indicators. A national
  series cannot populate a 10-metro ranking, so it was not used as an
  indicator and no FRED value appears in the model.

## Actually used: clearly-labelled illustrative dataset

- File: `data/metro_indicators.csv`, generated by
  `src/generate_illustrative_data.py` (invoked via `src/fetch_data.py`).
- Flag in the CSV itself: every row carries
  `data_source = "illustrative (author-set, NOT official FRED/BLS/Census)"`.
- The 10 metros and 7 indicators are listed in README.md with definitions.
- Values are round, author-chosen magnitudes in plausible ranges, chosen
  to encode relative differences for a teaching model — **not measured
  facts, not official statistics, and not to be quoted as such**.

## Method sources (for the method, not the values)

- Min-max normalisation and weighted composite scoring: standard
  multi-criteria decision analysis practice; direction per indicator is
  documented in README.md.
- Monte Carlo weight sensitivity: lognormal perturbation of weights with
  renormalisation, seed 42, 2,000 runs — method stated in README.md and
  `outputs/metrics.json`, so the stability percentages are reproducible
  from the code, not from any external source.
